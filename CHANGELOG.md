# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-05-20
### Added
- **AI Concierge**: Persistent floating chatbot powered by Gemini.
- **Itinerary Planner**: Genkit-driven personalized schedule generation.
- **Queue Predictor**: Wait-time analysis for stadium amenities.
- **Premium UI**: Implemented Glassmorphism design system and sleek transitions.
- **Safety Center**: Dedicated emergency and first-aid resource hub.

### Changed
- Refactored navigation to support both Desktop Sidebar and Mobile Bottom Nav.
- Optimized image loading using Next.js `Image` component and placeholder system.

### Fixed
- Improved mobile responsiveness on the Venue Map component.
- Corrected alignment issues in the Concession Ordering menu.
