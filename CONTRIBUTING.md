# Contributing to VenueFlow

We are thrilled that you are interested in contributing to VenueFlow! To maintain high code quality and consistency, please follow these guidelines.

## Process

1. **Fork** the repository.
2. **Create a branch** for your feature or bug fix: `git checkout -b feature/amazing-feature`.
3. **Commit** your changes with clear, descriptive messages.
4. **Push** to your branch: `git push origin feature/amazing-feature`.
5. **Open a Pull Request** against the `main` branch.

## Standards

- **TypeScript**: All new code must be fully typed.
- **UI Components**: Use existing Shadcn components where possible.
- **Styling**: Stick to Tailwind CSS utility classes and the defined HSL theme.
- **Testing**: Ensure any logic changes are manually verified across mobile and desktop views.

## Feedback

If you find a bug or have a feature request, please open an Issue on GitHub.
